# Shujuan Delegate

Trigger for handoff, worker packet, reviewer return, provider impact output, independent review, explicit parallel subagent work, or material import.

Do not trigger for final closure unless the controller is adopting material through closeout primitives.

Anti-drift: ordinary multi-task prompts use Harness Task Relation Matrix first; Delegate is for explicit role-bounded material, not automatic subagent spawning.

First surface: packet, endpoint active report, changed files, tests, and authority boundary.

Action chain: state role, scope, authority boundary, expected return fields, required reading, tests/impact expectations, and adoption rule.

Completion: return material names changed/inspected files, tests, findings, risks, and says it is not closure evidence before controller adoption.
