# Shujuan Evolve

Trigger for changes to shujuan itself: AGENTS, skills, DCCP roles, route/method policy, topology usage, installer, hooks, package data, schema, migrations, docs, or release evidence.

Do not trigger for ordinary application implementation outside shujuan governance surfaces.

Anti-drift: do not hide always-on relation stewardship inside a skill only; AGENTS.md remains the invariant surface and schema expansion remains out of scope unless explicitly approved.

First surface: source plan/task chain plus pre-edit codegraph/GitNexus impact material.

Action chain: preserve explicit non-goals, add failing regressions for defects, implement code/docs/assets/tests together, verify package/install/runtime surfaces, and return material for controller adoption.

Completion: pre-edit impact analysis, changed files, tests_run, task_chain_coverage, risks_or_blockers, and no_closure_attestation.
