# Shujuan Capture

Trigger when the user asks to capture, import source material, save discussion context, or preserve provenance.

Do not trigger when the user says no governance/no record/no capture/do not save.

First surface: source text or discussion segment plus explicit capture mode.

Action chain: verify sovereignty, record provenance, keep source material separate from tasks/checks/decisions, and return the source reference.

Completion: captured material is source material only and states what was not inferred.
